# 💰 存钱妙具 (HaoSaveMoney)

**存钱妙具** 是一款专为我自己（一个正在学习技术的学生）打造的极简记账与预算管理 App。
开发它的核心理念是**“先定存钱目标，再算每日可用预算”**，帮我治好月底吃土的毛病！

## 💡 开发初衷 (Motivation)
作为一名学生，我开发这个 App 并不单纯是为了记账，更是为了**学习和实战**：
1. **养成财务习惯**：记录并分析自己真实的消费行为。
2. **打造专属学习数据库**：与其在网上找枯燥的测试数据，不如把我自己日常积累的消费记录当作最完美的“真实数据源”。App 内置了将所有账单数据完整导出为 SQL 语句的功能，方便我随时导入到电脑上的数据库中，实地操作并练习复杂的 SQL 查询，做到学以致用。

## ✨ 核心功能
*   **📊 智能预算引擎**：输入月生活费与固定开销，选择存钱策略（保守/标准/激进），App 自动算出我今天到底还能花多少钱。
*   **🛒 极简随手记**：专注于“今天花了多少”，每次记录自动更新当日和当月剩余可用预算。
*   **📈 数据看板**：直观展示当月消费进度、存钱目标达成率，防超支利器。
*   **💾 SQL 导出助手**：一键将本地账单数据转化为标准 SQL 脚本，随时随地开启我的数据库练习模式！

## 🚀 如何下载体验
请点击网页右侧的 **[Releases]** 标签页，下载最新版本的 `.apk` 安装包，直接安装到 Android 手机上即可。如果你也想拿自己的真实消费数据来练 SQL，欢迎使用！
