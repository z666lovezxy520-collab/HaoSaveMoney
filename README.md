# 💰 存钱妙具 (HaoSaveMoney)

**存钱妙具** 是一款极简的记账与预算管理 App。
它有别于传统的流水账式软件，核心理念是**“先定存钱目标，再算每日可用预算”**，帮你告别月底吃土！

## ✨ 核心功能
*   **📊 智能预算引擎**：输入月收入与固定开销，选择存钱策略（保守/标准/激进），App 自动算出你今天还能花多少钱。
*   **🛒 极简随手记**：专注于“今天花了多少”，每次记录自动更新当日和当月剩余可用预算。
*   **📈 数据看板**：直观展示当月消费进度、存钱目标达成率，防超支利器。
*   **💾 数据安全**：所有数据均保存在手机本地，并支持导出为 SQL 文件。
